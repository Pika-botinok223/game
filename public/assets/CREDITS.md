# Asset credits

All assets are CC0 / public domain. Third-party assets are by Kenney (https://kenney.nl, CC0 1.0). Everything marked "CC0 (generated for Ave Maria)" was synthesised procedurally by the Ave Maria project (no third-party material).

Kenney asset pages: Space Kit, Platformer Kit, Furniture Kit, Animated Characters 1 and 2, Impact Sounds, UI Audio, Interface Sounds; Starter-Kit-FPS (GitHub KenneyNL, assets CC0). Files were obtained through the public GitHub mirrors https://github.com/ETdoFresh/kenney.nl and https://github.com/KenneyNL/Starter-Kit-FPS. Kenney models were converted to GLB (and some recoloured / rescaled) by the Ave Maria project.
